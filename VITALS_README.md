# 🏥 Constantes Vitales - Guide de Bienvenue

## 👋 Bienvenue!

Vous êtes dans le système de gestion des **constantes vitales** de l'e-Santé.

Cette nouvelle fonctionnalité permet aux **infirmières** d'enregistrer et de gérer les constantes vitales des patients, tandis que les **patients** et les **docteurs** peuvent les consulter.

---

## 🎯 Commencez Maintenant

### Je suis... Infirmière 👩‍⚕️

**Que puis-je faire?**
- ✅ Enregistrer les constantes vitales d'un patient
- ✅ Voir l'historique des mesures
- ✅ Modifier une constante si nécessaire
- ✅ Supprimer une constante si erreur
- ✅ Calculer automatiquement l'IMC

**Comment commencer?**
1. Lire: [VITALS_QUICK_START.md](VITALS_QUICK_START.md#pour-linfirmière)
2. Ouvrir: Menu → Espace Infirmière → Constantes Vitales
3. Remplir le formulaire et cliquer "Enregistrer"

**Aide rapide:** [VITALS_QUICK_START.md#-aide-rapide](VITALS_QUICK_START.md)

---

### Je suis... Patient 👤

**Que puis-je faire?**
- ✅ Consulter mes dernières constantes
- ✅ Voir l'historique complet

- ✅ Interpréter les codes couleur

**Comment commencer?**
1. Lire: [VITALS_QUICK_START.md](VITALS_QUICK_START.md#pour-le-patient)
2. Ouvrir: Menu → Dossier Médical → Constantes Vitales
3. Consulter les données affichées

**Comprendre les données:** [VITALS_QUICK_START.md#2️⃣-comprendre-les-constantes](VITALS_QUICK_START.md)
